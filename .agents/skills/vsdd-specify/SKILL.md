# Specify
Write observable behavior using Given/When/Then or equivalent. Assign stable FR/AC IDs. Each acceptance criterion must be measurable and independently verifiable. Keep implementation choices out unless they are explicit constraints from a source. Preserve unresolved product decisions as open questions; do not fill in automotive timing, thresholds, priorities, interfaces, or fail-safe behavior by guesswork.
