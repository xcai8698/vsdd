# Feature brief: speed warning

- Feature ID: FB-001
- Source: illustrative user request in this example; not an approved product requirement
- Status: illustrative / proposed

## Outcome
Allow a speed limit to be configured and provide a visual/audible warning when the vehicle exceeds the configured limit.

## Scope
- In scope: represent the feature intent and traceability pattern.
- Out of scope: production thresholds, timing, HMI priority, failure response, safety classification and platform-specific signal contracts.

## Open questions
- How is exceeding the configured limit defined, including equality, hysteresis and filtering?
- What are the required warning onset/clear timing and priority?
- Which authoritative interface owns speed, configured limit, sound and telltale requests?
- What are the failure, diagnostics and degraded-mode requirements?
