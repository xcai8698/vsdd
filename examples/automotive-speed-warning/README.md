# Example: automotive speed warning

This example illustrates how VSDD artifacts connect a Feature to system/software requirements and verification. It is a workflow example, not a production-ready automotive specification.

## Example behavior

A customer asks for a speed-limit setting and an over-limit audible/visual warning. A separate turn-signal example uses a signal value of 1 to activate a telltale/prompt and 0 to deactivate it. Those statements are only the example's supplied intent. Threshold comparison details, hysteresis, timing, prioritization, HMI behavior, failure behavior, signal ownership, diagnostics and safety classification remain unresolved until authoritative requirements are provided.

## How to use it

Review the artifacts in this folder and look for stable IDs, source links, explicit open questions, and verification mapping. Do not treat illustrative IDs or proposed requirements as customer-approved requirements.
